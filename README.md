# Luyện Thi CLC & TIMO

Web app ôn luyện và thi thử vào lớp Chất Lượng Cao (CLC) và Toán TIMO. Chạy hoàn toàn trong trình duyệt:
dữ liệu (câu hỏi nhập vào, lịch sử, thống kê) lưu trong trình duyệt của bạn và không gửi đi đâu.

- Mở trang, chọn bộ đề CLC hoặc TIMO ở góc trên.
- Có sẵn 30 câu mẫu mỗi bộ (tự viết). Thêm đề riêng ở mục **Ngân hàng đề** (Excel, Word, PDF, văn bản hoặc JSON).
- Dùng **Sao lưu / khôi phục dữ liệu** ở chân trang để chuyển dữ liệu giữa các thiết bị.
